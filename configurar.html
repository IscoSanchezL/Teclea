Asistente de configuración

Sigue los 4 pasos en orden. Todo se hace desde el navegador: no necesitas instalar nada. Esta página no envía tus datos a ningún sitio.

1Pega la configuración de Firebase

En console.firebase.google.com → tu proyecto → ⚙ Configuración del proyecto → Tus apps → app web → “Configuración del SDK” → copia todo lo que está entre llaves { … } y pégalo aquí.

Descarga el archivo y súbelo a tu repositorio de GitHub reemplazando js/core/config.js (GitHub → carpeta js/core → “Add file” → “Upload files” → “Commit changes”).


    

  


  

    
2Activa el acceso y las reglas de seguridad

    
    
    
    
    
Reglas de seguridad: cópialas y pégalas en Firestore → Reglas → Publicar.

     
    
  


  

    
3Prueba la conexión

    
Comprueba que tu configuración funciona y que las reglas están publicadas.

    
    

  


  

    
4Primer ingreso del administrador
